# AI Audit Finding Tracker — Summary Card

## Project Overview
The AI Audit Finding Tracker is an AI-powered backend service designed to analyse, categorise, and process audit/security findings using Large Language Models and intelligent workflows.

The system supports automated classification, prompt-based analysis, caching, asynchronous processing, and vector database integration.

---

# Key Features

## AI Categorisation
- Categorises audit/security findings using Groq LLM APIs
- Returns category, confidence score, and reasoning

## Async Report Processing
- Supports asynchronous workflow execution
- Tracks background job status

## Redis Caching
- Reduces repeated AI API calls
- Improves response performance

## ChromaDB Integration
- Stores vector embeddings
- Enables semantic search and retrieval

## Prompt QA Testing
- Validates prompt quality and AI responses
- Generates evaluation reports

## Performance Testing
- Measures API response stability and speed
- Validates deployment readiness

## Docker Deployment
- Containerised AI service
- Redis service integration
- Portable deployment support
